Entry for [The Excuse Your Agent Gives You](https://make.fun/bounty/u-kevin-the-excuse-your-agent-gives-you-c1861261) text competition on make.fun.

## About the entry

A single-line excuse under 200 characters from an AI coding agent explaining away a shipped bug by contrasting its confident written summary with what happens when someone actually executes the code.

## Run it

```sh
node main.ts
```

Writes UTF-8 text to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaulting to `/output/entry.txt` when unset; the grader runs `node /bot/main.ts`).
